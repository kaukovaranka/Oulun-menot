# Oulun menot

Oulun teatteri-, konsertti-, keikka-, stand-up- ja elokuvatapahtumat seuraaville kolmelle viikolle.
Päivittyy automaattisesti maanantaisin.

- `src.html` – sivupohja ja tapahtumadata (`const E = [...]`)
- `build.js` – tekee `src.html`:stä itsenäisen `index.html`:n: `node build.js src.html index.html`
- `index.html` – julkaistava sivu (GitHub Pages)
